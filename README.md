# Buyer Intent & Lead Scoring

Predicting which website visitors will buy, using 12,000+ real shopper sessions
(UCI Online Shoppers Purchasing Intention dataset).

**What's inside:** data cleaning, EDA with Seaborn, K-Means visitor segmentation,
Logistic Regression / Random Forest / Gradient Boosting models (best ROC-AUC ~0.93),
permutation importance, a Hot/Warm/Cold lead scorecard, and product recommendations.

**Tools:** Python, Pandas, Scikit-learn, Seaborn, Google Colab

[Open in Colab](https://colab.research.google.com/github/ShreyaBagati/buyer-intent-lead-scoring/blob/main/Buyer_Intent_Lead_Scoring_Project.ipynb)

Dataset: Sakar et al. (2019), UCI Machine Learning Repository.
